# Technical Communication: User Experience

## 1. Overview
The Guest Interface is designed for high-end immersion, allowing users to browse the "Curated Menu" and place VIP orders directly from their device.

## 2. Order Process
1. **Selection:** Users browse by category (Cocktails, Small Plates, Mains, Apartments).
2. **Cart Management:** Real-time calculation of totals and service charges.
3. **Authentication:** Required for order confirmation to ensure valid Guest IDs.
4. **Tracking:** Visual feedback once the order is "Confirmed" via the on-device terminal.

## 3. Theming & Interaction
- **Aesthetic:** Dark mode primary (`#0A0A0B`) with Gold accents (`#D4AF37`).
- **Feedback:** Uses `framer-motion` for fluid transitions between menu categories and cart interactions.

## 4. Data Privacy
- Guest names and IDs are only visible to authorized Staff/Admin.
- Payment information is processed via secure external gateways (simulated in prototype).
